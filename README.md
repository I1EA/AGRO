# RoboFarm Water Saver

Web e-prototype for **Idea’Wave / Innov Travel Morocco 2026** (Euromed Fès, 16–17 November 2026). A farm simulation and copiable hardware plan for a water-saving irrigation rover aimed at Moroccan cooperatives.

The robot measures soil and air, georeferences samples (GPS + IMU), and an application recommends **where, when and how much** to irrigate. This repo is the Next.js stand-in for the Flutter dashboard in the pitch: mock telemetry, two BOMs, Arduino wiring, MQTT payload.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL printed by Next.js (this project binds **port 4371**).

```bash
npm run build && npm run start
```

No database and no auth. Telemetry is generated by `GET /api/telemetry`.

## BOM snapshot

Prices are taken from public vendor pages (Arduino Store, SparkFun, Adafruit, Addicore, Amazon, AliExpress, RS) and converted with **1 EUR ≈ 10.85 MAD** and **1 USD ≈ 9.95 MAD** (approx., Nov 2026). Rows marked **approx.** are catalogue bands, not a quoted SKU. Freight and Moroccan duty are excluded. Totals are computed in the Pricing page so they stay in sync with the table.

## Simulation model

Traditional volume is a calendar m³/ha/day by crop, scaled by weather. RoboFarm reduces that with a zone factor and skips irrigation in rain. The **savings % is a model gap, not a promise**. The pitch cites Dong et al., *Frontiers in Water* (2024) ~30 % on tomato as literature, not a RoboFarm result.

## Arduino

See `/materiel` and `public/firmware/robofarm_prototype.ino`. Bench path: Nano ESP32 + Uno Rev3, capacitive soil, DHT22, YF-S201, float, optional rain, NEO-6M, MPU-6050, 12 V solenoid on a relay.
